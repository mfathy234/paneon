Everything you need to run several agents

  • Three agents in one grid

    1 to 6+ real terminals laid out automatically. Maximize any pane, zoom text per project.

  • Resume any session

    Panes come back on the next start. Ctrl+Shift+R lists earlier sessions of all three agents.

  • Command palette

    Ctrl+K searches sessions, actions, projects, snippets and layouts in one list.

  • Ask two agents

    Send one prompt to two agents, each in its own worktree, and compare the results.

  • Continue in another agent

    Hand a session to Codex, Gemini or Claude with an editable summary of goal, files and last error.

  • Saved layouts and snippets

    Bring a whole setup back by name. Insert prompt snippets with Alt+1 to Alt+9.

  • Usage view

    Tokens by day, project and agent, plus limit history, read from the agents' own folders.

  • Needs-you alerts

    A pane that finishes or waits on a permission prompt gets an amber border and a notification.

  • In-app updates

    The installed build updates itself from GitHub Releases while your sessions keep running.

  • The paneon command

    Start, resume and open layouts from the terminal you already have open.

  • Themes

    Eight themes with contrast checks, plus an optional background image.

  • Everything local

    No account, no telemetry. Nothing leaves your machine.

How it works

  1. Install

    Run the installer or the portable exe. Sign in once to each agent CLI you use, in any terminal.

  2. Add projects

    Pick a folder and a default agent. A short first-run setup shows which CLIs it found.

  3. Start sessions

    Press Ctrl+N, or run paneon . in a folder. Each agent runs in its own pane.

  4. Stay on top

    Glance at status, plans and context. Come back when a pane asks for you.

The paneon command

The installer adds it to your PATH. Open a new terminal and drive Paneon from where you already work.

# add this folder and start its agent
paneon .

# start a specific agent on a project
paneon start billing-api --agent codex

# pick up the newest session
paneon resume --last
